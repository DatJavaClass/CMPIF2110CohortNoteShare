================================================================
1. THE CHARACTERISTICS OF RELATIONAL DATABASES
================================================================
  - Purpose of a database: help people track things of interest
    to them.
  - Two categories: relational and non-relational.
  - KEY TERM: Big Data: enormous datasets.
  - Data lives in tables with rows (records) and columns
    (fields), like a spreadsheet.
  - A database may have multiple tables, each about a different
    thing. Each row is one occurrence or instance of that thing.
  - A database stores data and relationships.

================================================================
2. NAMING CONVENTIONS IN THE TEXTBOOK
================================================================
  - Table names in all capitals (the notes list STUDENT, CLASS,
    GRADE, COURSE_INFO).
  - Column names start with a capital, compound names capitalize
    each word (the notes list Term, Section, ClassNumber,
    StudentName).
  - Adjacent example: table VEHICLE, columns PlateNumber,
    MakeName, ModelYear (adjacent example).

================================================================
3. A DATABASE HAS DATA AND RELATIONSHIPS
================================================================
  - Relational databases store data and have relationships among
    rows of data.
  - KEY TERM: primary key: identifies each row of a table.
  - KEY TERM: surrogate key: automatically assigned by the
    database and used as a primary key.
  - KEY TERM: composite key: more than one column used as the
    primary key, when needed.
  - KEY TERM: foreign key: the link between two tables that
    provides the link to a relationship.

================================================================

  - Figure 1-6, Microsoft Access 2019 view: key symbols on

  - Adjacent example with the same lesson (adjacent example):

      DOCTOR (DoctorNumber, DoctorName, Specialty, Office).
      VISIT (PatientNumber, DoctorNumber, VisitDate).
    A VISIT table holding only dates tells you nothing. Add the
    two foreign keys and each visit is tied to one patient and
    one doctor. Composite key (PatientNumber, DoctorNumber,
    VisitDate) if a patient can see the same doctor more than
    once. One patient to many visits, one doctor to many visits.

================================================================
5. DATABASES CREATE INFORMATION
================================================================
  - KEY TERM: data: recorded facts and figures.
  - KEY TERM: information: knowledge derived from data, OR data
    presented in a meaningful context, OR data processed by
    summing, ordering, averaging, computing, or other similar
    operations.
  - Databases record data in such a way that information can be
    produced from it. The STUDENT, CLASS, and GRADE data could
    yield each student's GPA.

================================================================
6. KEY TAKEAWAYS
================================================================
  - Track things of interest. Relational vs non-relational. Big
    Data = enormous datasets.
  - Tables, rows (records), columns (fields). One table per
    thing, one row per instance.
  - Data plus relationships. Values without foreign keys are
    orphans.
  - Primary, surrogate, composite, foreign: know all four
    definitions cold.
  - Data = recorded facts and figures. Information = data made
    useful.

================================================================
7. QUIZ-SAFE FACTS
================================================================
  - Row = record. Column = field.
  - Two categories of databases: relational and non-relational.
  - Enormous datasets are called Big Data.
  - Table names ALL CAPS, column names initial capital, compound
    column names capitalize each word.
  - Surrogate key: automatically assigned by the database, used
    as primary key.
  - Composite key: more than one column as primary key.
  - Foreign key: the link between two tables.
  - GRADE's primary key in the textbook figures is the composite
    (StudentNumber, ClassNumber), and both are foreign keys.
  - Access relationship symbols: key = primary key, 1 and
    infinity = one to many.
  - Three definitions of information: knowledge derived from
    data, data in a meaningful context, data processed by
    summing, ordering, averaging, computing, or similar.
